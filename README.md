Project Title
AI-Based Smart Menstrual & PCOS/PCOD Early Risk Monitoring System
Project Description
This project is an AI-powered web application designed to provide preliminary PCOS/PCOD risk assessment using user-provided health information.
The system collects details such as menstrual-cycle patterns, age, BMI, acne, hair growth, weight changes, sleep, exercise, stress level, family history, and optional health-test values.
An AI/ML model processes these inputs and provides an understandable risk level along with general recommendations.
The main purpose is early awareness and preliminary screening, not medical diagnosis.

Main Points
AI-Based Risk Assessment: Uses machine-learning techniques to estimate PCOS/PCOD risk.
Health Questionnaire: Collects relevant menstrual, lifestyle, and health information.
Risk Classification: Provides Low, Moderate, or High Risk results.
Personalized Feedback: Gives understandable recommendations based on the assessment.
Prediction History: Allows users to compare their assessments over time.
Web-Based Platform: Provides an accessible interface for users to enter their information and receive results.
ML Pipeline: Data collection → cleaning → feature engineering → model training → validation → prediction.
Possible ML Models: Logistic Regression, Decision Tree, Random Forest, XGBoost, and SVM. AI_Based_PCOS_PCOD_Risk_Monitoring_Presentation.pptx
Technology: React, HTML, CSS, JavaScript, Python, FastAPI/Flask, Scikit-learn, Pandas, NumPy, and MySQL/MongoDB. AI_Based_PCOS_PCOD_Risk_Monitoring_Presentation.pptx
Security: Password hashing, HTTPS, input validation, role-based access control, and protection against common web attacks. AI_Based_PCOS_PCOD_Risk_Monitoring_Presentation.pptx
Future Scope: Mobile application, wearable integration, doctor portal, multilingual support, voice-based input, AI chatbot, and continuous risk monitoring. AI_Based_PCOS_PCOD_Risk_Monitoring_Presentation.pptx
Objective
The main objective is to make early PCOS/PCOD risk awareness more accessible by providing a simple questionnaire-based system
that analyzes multiple health factors and presents the result in an easy-to-understand format.
